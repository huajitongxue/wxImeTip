## 新增：自动构建与发布

本项目现在用 **GitHub Actions** 自动打包：推一个版本标签，GitHub 的构建机就会
自动编译两个版本并挂到这个页面。

在此之前，每个版本都是在我本机编译、手动上传的（还得先关掉正在运行的程序）。
从这一版开始不需要了。

**对使用者的影响：没有。** 下载的文件、功能、用法完全一样 ——
只是从这个版本起，Release 里的文件由 GitHub 的构建机编译产出。
